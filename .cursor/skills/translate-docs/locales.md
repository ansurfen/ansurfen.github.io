# Docs locale reference

## Paths

| Locale | Display name | Docs prefix |
|--------|--------------|-------------|
| en_us | English | `docs/en_us/` |
| zh_cn | 简体中文 | `docs/zh_cn/` |
| zh_tw | 繁體中文 | `docs/zh_tw/` |
| ja_jp | 日本語 | `docs/ja_jp/` |
| fr_fr | Français | `docs/fr_fr/` |
| es_es | Español | `docs/es_es/` |
| pt_pt | Português | `docs/pt_pt/` |
| ru | Русский | `docs/ru/` |
| ar_sa | العربية | `docs/ar_sa/` |

## Content kinds

| Subdir | Frontmatter keys |
|--------|------------------|
| `blog/` | `pubDatetime`, `title`, `description`, `category`, `series?`, `tags`, `draft?`, `image?` |
| `projects/` | `name`, `description`, `technologies`, `type`, `image?`, `sourceCode?`, `preview?` |

## Slug

Use the **same basename** across locales (`hulo-dev-1.mdx`, not a translated filename).
