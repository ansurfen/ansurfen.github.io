## 被制造出来的「风口」

Agent 开发并没有想象中那么多**独立岗位**。很大一部分热度，来自培训班和卖课机构制造的焦虑——先把你吓住，再煽动你跳进 Agent 赛道。

真到了公司里，RAG、Agent、LLM 这几块，往往让后端同学花点时间研究，再配一轮 Vibe Coding，就能搓出一个**能演示的 Demo**。门槛并没有课程宣传得那么高——但要分清两件事：**做出 Demo** 和 **上线可运维、可审计、可规模化**，中间差的是评测、权限、成本、幻觉治理、和存量系统对接，这些往往才是人力大头。

更准确的说法不是「没有 Agent 需求」，而是需求在**下沉**：融入现有产品、后端、数据、安全岗位，而不是单独长出一个巨大的「Agent 开发行业」。

## 产品真相：塞数据，不是造需求

看看市面上的应用：名义上和 AI 结合了，细想一层，多数仍是**把数据塞进去，把结果吐出来**。

于是大量 ToC Agent 创业难做深——这不等于 ToC 完全没有市场（写作、修图、陪伴、通用助手都有先例），而是**多数团队做的 ToC Agent 没有护城河、留存差、难形成付费习惯**。企业侧也一样：很多业务并不需要 Agent，顶多做套 RAG、搭个智能客服，需求天花板一眼可见。

智能客服又是高度流程化的活：模型可换、多路召回可配、解析模式可插拔、数据库可替换，YAML 一写，开源项目一抄，就能跑起来。标准化会压缩「纯集成、纯抄开源」的空间，但企业仍会为**私有化、合规、效果 SLA、行业数据治理**买单——形态会变，不会一夜归零。

## 高薪幻象：外包、叠要求、与招聘乱象

### 岗位本身

Agent 岗位看起来薪资不低，拆开看，**不少**是外包名义下的包装（经济下行周期里，大厂把正编转外包并不罕见）。同时也有一些正编在做平台、推理、编排、安全——不能把整条赛道都等同于外包。

要求却在叠加：既要全栈，又要 LLM。可 Agent 编排本身高度模板化，能持续开发的场景并没有课程里展示的那么多。Coding Agent、旅游规划、医疗规划——除非你已经在这个行业，或本来就是从业者，否则半路出家往往缺两样东西：**领域专业知识**和**运营经验**。对企业来说，让现有后端研究、转岗，往往比外招一个「只会搭 Demo」的人更划算。

### 招聘平台的另一重乱像

和 Agent  hype 配套的，还有招聘侧的**表演式不匹配**：

- JD 写得像万能清单：RAG、微调、Agent 框架、全栈、大厂背景、即战力，薪资区间却按普通开发给；
- 你按 JD 改简历，关键词对齐、项目描述对口，系统推荐也显示「匹配度高」；
- 一面没进，或 HR 直接一句：**「不太合适」**——不给具体原因，或原因与 JD 对不上（要「有从 0 到 1 的 Agent 产品」，你写了企业内落地；要「懂业务」，你本来就是行业转码）。

这不是单纯的「你不够优秀」，而是几种结构叠加：

1. **岗位未必真招**：挂 JD 收简历做人才池、应付 headcount、或早已内定，平台只是漏斗入口；
2. **JD 是愿望清单，不是筛选标准**：写的人（HR/业务）和筛的人（HR/用人经理）不是同一套逻辑，简历匹配算法看的是词，人看的是「像不像自己人」；
3. **Agent 岗名大、定义糊**：同叫「Agent 工程师」，一家要调 prompt 做客服，一家要造 IDE，一家要数据标注流水线——简历符合 A 版 JD，在 B 公司眼里就是「不合适」；
4. **供过于求后的礼貌拒绝**：「不合适」是成本最低的回复，比告诉你「预算只够外包」「我们更想要便宜应届生」省事。

结果是：**求职者被 JD 训练着投，HR 被 KPI 训练着筛，两边都在平台上完成仪式，真实匹配反而变少。** 这和卖课制造焦虑是同一套逻辑——外面看起来很热闹，你进去才知道门往哪开、钥匙在谁手里，没人告诉你。

## Coding Agent：入场券窄，工程化更深

有人会说：Coding Agent 总该算计算机行业的知识吧？

能进 Claude Code、Codex、Cursor、国内 Trae 这类团队的人极少；市场上更多的岗位是「用 AI 写业务」，不是「做 AI IDE」。你拿 Vibe Coding 做出来的玩具项目，很难直接接手**产品级** Coding Agent——那需要的是上下文工程、多文件编辑、diff、稳定性、企业策略，是团队级交付，不是「原有 IDE 大牛顺手接个 API」就能等价替代。

招一个只会 Vibe Coding、工程素养不足的新人，要补代码理解、补规范，还要防「一键生成、直接提交」——给他做 Code Review，有时还不如资深工程师自己用工具来得快。

**更可能改写行业的人**，是「原工程能力 + 新 AI 能力」的复合体：懂系统、懂业务，再把 LLM 嵌进现有工具链；而不是只懂框架、不懂领域的纯外行主导。

## 结语

Agent **存在**，但被**过度叙事**了；培训、JD、平台匹配度，都在放大「你很缺、快上车」的感觉。

少被焦虑带着跑，多问自己三件事：

1. 我要解决的是真问题，还是「塞数据出结果」的壳？
2. 目标公司是招**落地集成**，还是招**叙事上的 AI 原生**？
3. JD 和简历「符合」，是否只代表关键词过关，不代表岗位真开、标准真清晰？

能回答清楚这些，比多报一门 Agent 课、多投一百份「高度匹配」的简历，更有用。
